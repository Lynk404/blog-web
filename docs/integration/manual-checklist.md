# 前后端联调手工清单

Written for: 你本人（在浏览器里逐项操作并记录结果）。接口细节见 [前后端对接说明](./frontend-handoff.md)。

## 一、启动前检查

- [ ] MongoDB 已启动，地址 `mongodb://127.0.0.1:27017/db_blog`
- [ ] `auth/` 下有四个密钥文件：`public.cer`、`private.cer`、`jwt-public.pem`、`jwt-private.pem`
- [ ] 已执行 `node scripts/sync-key.js`
- [ ] 后端已启动：`npm start`，访问 `http://127.0.0.1:3000/keys` 返回 JSON 且 `data.pubKey` 有内容
- [ ] 前端已启动，前端使用 RSA-OAEP + SHA-1 加密密码（**必须确认，否则下面所有登录都会失败**）
- [ ] 打开浏览器开发者工具：Network 面板、Console 面板，全程保持打开

## 三、注册与登录

| # | 操作 | 预期 | 结果 |
| --- | --- | --- | --- |
| 3.1 | 注册：用户名不合规（如 `abc`） | 前端提示格式错误，不发请求或服务端返回 422 | |
| 3.2 | 注册：密码不合规（如 `abc`） | 前端提示格式错误 | |
| 3.3 | 注册：邮箱格式错误 | 提示邮箱不合法 | |
| 3.4 | 注册：使用临时用户名（6–8 位字母数字，如 `tmp`+5 位数字） | 注册成功，自动进入登录态（拿到 token） | |
| 3.5 | 再次用同一用户名注册 | 提示 `用户名不能重复` | |
| 3.6 | 退出登录 | token 被清除，页面回到未登录态 | |
| 3.7 | 用错误密码登录 | 提示 `账号密码错误` | |
| 3.8 | 用正确密码登录 | 进入登录态，token 保存在前端 | |
| 3.9 | 登录后刷新页面 | 仍保持登录（token 未丢失） | |
| 3.10 | 在 Network 中检查登录请求体 | `password` 是 base64 字符串（约 344 字符），**不是明文** | |
