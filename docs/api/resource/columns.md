# 专栏资源 (Columns)

> 基础路径：`/api/rest/columns`

## 字段说明 (Body)
| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `name` | String | 是 | 专栏名称（唯一） |
| `uid` | String | 否 | **禁止前端传值**，后台自动注入当前用户 ID |

> **创建时只接受 `name` 字段**，其余字段一律忽略。`aids`、`date` 由服务端维护。

## 特殊规则
1. **更新限制**：`PUT /api/rest/columns/:id` 只能修改 `name`，且必须是专栏创建者本人操作。
1.1 **删除限制**：`DELETE /api/rest/columns/:id` 只能由专栏创建者本人操作，非创建者返回 `403`。
1.2 **级联删除**：删除专栏时，**专栏下的所有文章一并删除（包括他人发表的文章）**，这些文章下的所有评论也一并删除（包括他人的评论）。规则与注销账号一致，前端应在删除前明确提示用户。
2. **关联查询**：获取专栏详情时，后台自动 populate 该专栏下的所有文章列表(`aids`)。
